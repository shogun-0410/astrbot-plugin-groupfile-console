## 二、v2.8.0 改动

### A 稳定内核

1. `client_for(event)` 按事件平台取客户端；`_bind_bot` 遍历平台选可用客户端。
2. `group_lock(gid)`：整理/删除/移动/确认串行。
3. `core/timeutil.py`：秒/毫秒/未来/0 统一归一；`ts=0` 永不参与 TTL。
4. `core/validate.py`：cron/规则/权限/TTL/容量/查重 normalize + clamp；非法值丢弃并 warning。
5. `core/scanner.py`：深度 10 / 文件夹 500 / 文件 5000 / folder_id 去重；整理与查重共用。
6. `core/ops.py`：AuditLog（JSONL 轮转）、TaskManager（进度/取消/历史）、RecycleStore（原位置索引）。
7. TTL 单次删除上限 `max_delete_per_run`（默认 200）。
8. 确认 key = `uid:gid`，跨群不能确认。

### B 运维能力

- 权限：view/move/delete/admin；旧 admins 名单等价 admin；面板可编辑 `permissions`。
- 审计：删除/移动/整理/建文件夹/TTL 回收删除/回收站还原/配置变更；`/gf 审计`。
- 任务：cleanup/dupes/scan/send_file，面板任务页进度/取消/历史。
- 回收站：TTL recycle 记录原位置；`/gf 恢复 <序号>` / 面板还原。
- 试运行：`/gf 预览` + 面板 TTL 预览（只报告）。
- 规则优先级：`priority` -100~100，参与命中评分。
- 容量趋势：`core/trend.py` 每日采样，面板总览 14 天柱状。
- 定时补跑：`cleanup.catchup_minutes`（默认 60），重启/卡顿后补一次，审计留痕。
- `/gf 列` 分页 30/页，序号为全量序号。

### C 面板

- 新增「任务」「审计」两页（任务进度/取消、审计筛选、回收站还原、运维设置）。
- 文件页分页；总览容量趋势；规则行 priority；群配置角色权限；定时补跑窗口；TTL 试运行按钮；响应式窄屏。
