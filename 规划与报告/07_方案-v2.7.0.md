## 二、v2.7.0 改动

### A. 发送目录（核心）

1. 新增 `core/sendtmp.py`：`default_send_dir / resolve_send_dir / is_under / plan_sweep / clamp_int / is_abs_path`（纯函数，可单测）。
2. 默认目录 = `get_astrbot_temp_path()/astrbot_plugin_groupfile_console/send_tmp`；
   优先级：面板自定义目录 > 插件配置 `deliver_dir` > 默认共享 temp。
3. 目录 777、父级 755、产物 666；发送前 `_ensure_readable`。
4. `send_dir_info()` 统一给 `/gf 状态`、`/gf 诊`、面板 `/send_tmp` 使用（dir/source/shared/inflight/last_sweep）。

### B. 清理策略（可配 + 兜底 + 不误删）

1. `groups.json` 新增顶层 `send_tmp`：`{enabled, keep_seconds, orphan_hours, dir}`，面板可改、立即生效。
2. 清理实现：`_schedule_cleanup`（延迟）+ `cleanup_sweep`（残留）+ `cleanup_tick`（10 分钟限流）+ 启动 10 秒后清一次。
3. in-flight：`_mark_inflight/_unmark_inflight`，延迟清理与 sweep 均跳过，30 秒重试、最多 20 次。
4. 失败兜底：下载失败即删；WebUI 直发失败按 60 秒延迟清理；成功直发后立即删（协议端已上传完）。
5. 只扫本插件发送目录；不碰 `groups.json` 与群文件。
6. **不改 auto_delete 语义**：TTL 默认 `report`，本次只清理「发送临时文件」。

### C. 规则 / 整理

1. `classify` 按 `kind`：`kw` 子串、`regex/dsl` 正则、缺省沿用旧行为；评分同步调整。
2. TTL：`ts<=0` 计入 `unknown_time`，只报告不动作。
3. 整理 stats 拆分 `no_rule / in_place / no_target`，报告新增「跳过原因」。
4. `qqfile`：移动/删除遇「文件不存在 / 目标文件夹不存在」立即停止重试。
5. `api_rules_set`：提示完全重复规则、多条兜底规则（不阻断保存）。

### D. 去空头 / 面板

- 删除 `move_only`、`delete_empty`、`report_used`（读取旧配置时忽略）。
- 删除 `api_group_status`、`qqfile.rename_file`。
- 面板：版本 2.7.0；「定时与维护」新增第 5 个分区「发送临时文件」（全局）：目录、来源、是否共享、保留秒数、残留小时、开关、立即清理；移除两个空头勾选。
- `/gf 状态` 降级显示；`/gf 删 <文件夹名>` 单参数给用法；`/gf 查 … 序号` 回复带清理秒数。
- README / `_conf_schema.json` / metadata 同步。
