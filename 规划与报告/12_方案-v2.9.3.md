## 二、统一交互模型

```
外层折叠（一个）
  └─ 范围说明一行
       ├─ 子折叠「导出」  ← 展开即生成（无「生成并显示」）
       │      textarea + 复制 JSON / 下载文件 + 状态
       └─ 子折叠「导入」  ← 展开即空
              textarea + 选择文件… / 确认覆盖导入 / 清空
```

三处入口共用这套模型与同一套 CSS（`.g-backup-sec`），视觉与行为完全一致。

## 三、三处范围写清

| 位置 | 标题 | 范围说明 |
| --- | --- | --- |
| 群卡 | 备份 **本群** 配置（导出 / 导入，整群迁移用） | 本群的规则/定时/容量/查重/管理员；导入覆盖本群，不影响其他群 |
| 总览 | 备份 **所有群** 的配置 | 本插件全部群；导入按群号覆盖合并，不影响备份以外的群 |
| 维护页 | 备份 **本群维护设置**（定时/容量/老文件/查重） | 只覆盖这四块，规则与管理员不动 |

## 四、文件页分区
