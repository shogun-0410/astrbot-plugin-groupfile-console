# v2.9.0 更新说明（精简 + 打磨 + 界面重排 · 2026-10-30）

主题：**删冗余、修本体、重排界面**。这不是加功能版本，是把 v2.8.0 加过头的东西收回来。

## 一、删除的功能（v2.8.0 加进来、实测用不上的）

| 删除项 | 原因 |
| --- | --- |
| **回收站 / 还原** | 实际没人用；TTL 的「移入 _回收 文件夹」动作本身保留，只是不再建索引、不再提供 `/gf 回收`、`/gf 恢复` |
| **任务中心 + 任务页** | 与面板同步操作重复，多一套状态机；整理/查重/扫描/发文件回到点完即出结果 |
| **容量趋势** | 群文件容量变化慢，采样与图表维护成本高于价值 |
| **权限分级（view/move/delete/admin）** | 回到「管理员 QQ + 全局管理员」，判断一条规则，不再有四级角色与面板权限编辑 |
| **规则优先级 priority** | 回到「匹配内容越长越具体」的单一规则，少一个让人困惑的旋钮 |
| **审计页 / 运维设置页** | 后端审计文件保留、`/gf 审计` 命令保留（出问题能查日志），不再单独开页 |

保留的 v2.8.0 内容都是修 bug 或低成本能力：按事件平台绑定客户端、按群互斥锁、秒/毫秒时间归一、配置校验、扫描深度/环保护、TTL 单次删除上限、确认绑定用户+群、`/gf 列` 分页、`/gf 预览`（试运行）、定时补跑窗口。

## 二、插件本体优化

1. 删除 `core/trend.py`、`core/ops.py` 里的 `TaskManager`/`RecycleStore`，`core/ops.py` 只留 `AuditLog`（约减 200 行）。
2. 权限判断收敛为单个 `_is_admin_user`，所有命令与确认流程共用。
3. 配置去掉 `ops` 段与群级 `permissions`，`groups.json` 结构变浅；旧配置读入时自动忽略多余字段并写回。
4. 面板删掉对应页面与接口，`apiFiles` 分页、`/gf 预览` 等真实有用能力保留。
5. pyflakes 全绿；单测 19 + 15 + 3 + 7 = 44 项通过。

## 三、界面重排（8px 体系）

新增一组布局变量，页面所有间距统一从这几个值取：

```css
--sp-1:4px --sp-2:8px --sp-3:12px --sp-4:16px --sp-5:24px --sp-6:32px
--pad-page:24px   页面左右留白
--pad-card:16px   卡片内边距
--gap-card:16px   卡片间距
--gap-ctl:8px     控件间距
--h-ctl:32px      输入/按钮高度
```

- 容器：`padding: 32px 24px 64px`；卡片：`16px 18px` + `margin-bottom 16px`；
- 标题区与内容 12px；工具栏 8px；表单栅格 8×16，列宽从 170px 提到 180px；
- 按钮统一 32px 高、小按钮 26px，不再出现 7/8/9px 混用；
- 输入框统一 32px 高 + 6px/10px 内边距；
- 导航 chips 4px 内距、4px 间距；
- 顺手修了 `.section-header h2` 里写错的 `align-align:center`（一直是无效声明）；
- 删掉重复的 `.btn-sm` 定义与后置冲突的 `.toolbar{gap:10px}`。

截图为证（1440 宽）：`dev_artifacts/screenshots/v29_*.png`（总览 / 定时与维护 / 文件 / 群配置）。

## 四、升级

- 覆盖安装 → 重载插件 → 控制台 `Ctrl+F5`；
- `groups.json` version 4，旧 v3 自动迁移：丢弃 `permissions`/`ops`、规则丢 `priority`，其余（规则/定时/TTL/容量/查重/管理员）全部保留；
- 旧 `recycle.json`/`tasks.json`/`trend.json` 不再读取，可手动删除。
