# v2.7.0 更新说明（2026-10-29）

主题：**发送链路修 EACCES + 清理策略可配 + 规则/整理去空头**

## 发文件不再 EACCES

- 发送临时目录默认改为 **共享 `temp/astrbot_plugin_groupfile_console/send_tmp`**（`get_astrbot_temp_path()`），
  协议端（SnowLuma/NapCat）能 `realpath` 读到；以前落 `plugin_data`，协议端容器根本没有这个路径。
- 目录 `777`、产物 `666`；发送前再补一次权限。
- `deliver_dir` 仍可覆盖（绝对路径），面板也可自定义；不在共享 temp 时 `/gf 状态`、`/gf 诊` 会黄字警告。

## 清理策略可配 + 失败兜底

- 新增「定时与维护 → 发送临时文件」：保留秒数（默认 600，30–86400）、残留小时（默认 1，1–168）、自动清理开关、立即清理按钮。
- 发送中保护：下载/直发期间标记 in-flight，延迟清理和残留清扫都会跳过，最多重试 20 次。
- 启动清一次、运行中每 10 分钟扫一次；只扫本插件发送目录。
- 失败兜底：下载失败立即删；WebUI 直发失败按 60 秒延迟清理；超限提示修正为 MB。
- 与群文件「老文件处理（TTL）」无关，`auto_delete` 默认语义不变。

## 规则 / 整理

- 规则 `kind` 真正生效：`kw` 按子串（`.apk.1` 不再把点当通配符），`regex/dsl` 按正则，缺 kind 保持旧行为。
- 时效清理：上传/修改时间都为 0 的文件视为「时间未知」，只报告、不回收不删除。
- 整理报告新增跳过原因（无规则 / 已在目标 / 规则未设目标 / 无时间）。
- 移动/删除遇到「文件不存在 / 目标文件夹不存在」不再盲目换 4 组参数重试。
- 保存规则时提示重复规则与多条兜底规则。

## 去空头

- 移除 `cleanup.move_only`、`cleanup.delete_empty`、`limits.report_used`（面板有开关、后端从未读取）。
- 移除死接口 `group_status`、死代码 `rename_file`。
- 面板版本统一 2.7.0；帮助/状态/诊断同步显示发送目录与清理策略。

## 升级

- 覆盖安装 `astrbot_plugin_groupfile_console` 目录 → 重载插件 / 重启 AstrBot → 控制台 `Ctrl+F5`。
- 配置数据结构兼容 `groups.json` 的 `version: 2`；新增顶层 `send_tmp` 段缺省用默认值。
- 旧 `plugin_data/.../send_tmp` 里若有残留，不再被自动扫描；确认无用后可手动删除。
