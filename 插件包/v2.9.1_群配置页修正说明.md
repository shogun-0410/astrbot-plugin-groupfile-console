# v2.9.1 更新说明（群配置页布局与逻辑修正 · 2026-10-30）

主题：修「管理范围 / 群基础设置」两个入口的间距、内部结构，以及该页的交互逻辑。

## 一、入口与间距

- 两级 chip 从「浮在页面底色上」收进同一张卡片（`.g-shell`），卡片内 `16px` 上、`12px` 下，与「定时与维护」一致；
- 去掉 `.subnav{margin:2px 0 14px}` 的 2px 贴边与 14px 非 8 倍数；
- 页面顶到卡片、卡片顶到 chip、chip 到内容全部走 8px 体系（4/8/12/16）。

## 二、内部结构

**管理范围**
- 统计数（已启用 N / 共 M）移到标题行右侧，不再和搜索框挤一行；
- 群行 `padding 8×12`、`gap 8`、行距 8（原来是 10/10/7 混用）；
- 「高级编辑 / 手动添加」默认收起，仅保留一个「＋ 手动添加 / 指定群号」入口；展开后是 2 列栅格（选择群 / 群号 / 备注名），按钮单独一行；
- 删掉第三个重复入口的说明文案（原「下方高级编辑」已不存在）。

**群基础设置**
- 卡片头只留：头像 + 群号 + 备注名（两行栅格）+ 「⋯ 配置备份」「折叠」两个次要按钮；
- 「导出配置」「导入配置」「删除群」从卡片头移走；
- 导出/导入收进折叠区 `导出 / 导入配置（整群迁移或备份）`，展开才显示；
- 删除群移到卡片底部**危险区**（分隔线上方提示、右侧红色按钮），与常规操作分离；
- 基础信息区去掉多余的「⚙ 群基础信息」小标题与外层 sub-panel 嵌套，直接铺在卡片里；
- 启用开关、管理员输入行、保存栏统一 8px 间距。

## 三、逻辑修正

| 问题 | 处理 |
| --- | --- |
| 点「配置」跳不过去（`switchToEdit(gid)` 里 `gid` 未定义 → ReferenceError） | 改为 `switchToEdit(r.id)`；实测点击后进入编辑页、选中该群、卡片渲染成功（DOM 断言 `data-pane=block / data-sel=10001 / data-card=yes`） |
| 勾选后整页重载、搜索框失焦 | 改为行内局部更新：提交后更新本地 `groupsData`、按最新数据重建映射并重绘列表，不重新请求接口 |
| 两个入口功能重叠（高级编辑与群基础设置都能改同一个群） | 手动添加收进折叠区，只做「新增/指定群号」；编辑一律走「群基础设置」 |
| 删除群与折叠同权重 | 移到危险区，红色按钮 + 说明文案 |
| 导出/导入占高频位置 | 收进折叠区 `details` |
