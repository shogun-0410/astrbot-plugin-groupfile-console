## 二、群基础设置：单个群 / 批量编辑

不牺牲单群折叠卡，用**二级 chip** 在同一页切换：

```
群配置
 ├─ 管理范围
 └─ 群基础设置
     ├─ 单个群     ← 现有的下拉 + 折叠卡（导出/导入/危险区）
     └─ 批量编辑   ← 群列表勾选 + 批量操作栏
```

批量编辑区结构：

- 顶部说明 + 「已选 N 个群」计数；
- 群列表（每行：勾选框 + 群名 + 群号 + 状态/管理员数/规则数），最大高 340px 内部滚动；
- 操作栏（一行，可换行）：全选 · 启用选中 · 停用选中 · 管理员 QQ 输入 · 追加管理员 · 移除管理员 · 结果提示。

批量只改**基础字段**（enabled / admins），规则、定时、时效、查重仍需去各自页签；这样不会误伤复杂配置。

## 三、实现要点

- `renderGroupsViews()` 同时渲染单群卡与批量列表；
- 批量提交后 `Object.assign` 本地对象 + 重绘列表与「管理范围」，不需要整页刷新；
- 批量失败逐群计数，最后统一提示「成功 N / 失败 M」；
- 缓存 `window.__gfcAvailable` 供批量后刷新「管理范围」列表复用，避免重复请求。
