# v2.9.3 更新说明（导出/导入冗余收敛 + 文件页分区 · 2026-10-30）

起因：用户指出「有导出/导入配置（整群迁移或备份）但是上面还有选择文件未选择文件」，是点「配置备份」后出现的，
并质疑是否只修一处、没有全量排查。这一版是**完整对账**的结果。

## 一、排查发现的冗余（不止一处）

| # | 位置 | 问题 |
| --- | --- | --- |
| 1 | 群卡 `.g-more`「⋯ 配置备份」 | **死按钮**，无事件绑定，点了无反应 |
| 2 | 群卡备份展开 | 导出块与导入块**同时铺开**，各带一套 textarea + 按钮 |
| 3 | 群卡导出块 | `生成并显示` 与「展开即自动生成」重复 |
| 4 | 群卡导入块 | `取消` 只隐藏不重置 |
| 5 | 总览「全局配置备份」 | 与群卡同构文案，无法区分范围；`生成并显示` + `导入（覆盖全部）` 两个开关各管一块 |
| 6 | 定时与维护 | 第三个「导出维护配置 / 导入维护配置」按钮组 + 独立面板 |
| 7 | 死 id | `g-edit-hint`、`m-hint`、`g-edit-modes` 在 HTML 但 JS 从不读 |
| 8 | 文件页 | 三行工具栏混排（浏览/分页/批量/新建/搜索），无分区标题 |

## 二、收敛结果

统一模式：**一个外层折叠 → 内层「导出」「导入」两个子折叠 → 展开即生成，无「生成并显示」**。

### 群卡（群基础设置）

```
备份 本群 配置（导出 / 导入，整群迁移用）
  范围：本群的规则 / 定时 / 容量 / 查重 / 管理员。导入会覆盖本群现有全部设置，不影响其他群。
  ▸ 导出本群配置        ← 展开即生成，只有「复制 JSON」「下载文件」
  ▸ 导入本群配置（覆盖）  ← 选择文件… / 确认覆盖导入 / 清空（真正复位）
```

- 删除死按钮 `.g-more`；
- 不再出现导出/导入两面板同屏铺开。

### 总览（所有群）

```
备份 所有群 的配置   范围：本插件全部群。导入按群号覆盖合并，不影响备份以外的群
  ▸ 导出所有群配置           ← 展开即生成（去掉「生成并显示」）
  ▸ 导入所有群配置（按群号覆盖合并）
```

- 去掉 `导入（覆盖全部）` 开关按钮（由子折叠承担）；
- 「清空」真正清空文本与提示。

### 定时与维护（仅维护四块）

```
保存维护设置 | 仅本群「定时 / 容量 / 老文件 / 查重」四块，不含规则与管理员     ▸ 备份这些设置
  ▸ 备份 本群维护设置（定时 / 容量 / 老文件 / 查重）
      ▸ 导出维护设置
      ▸ 导入维护设置（覆盖这四块）
```

- 顶部原来的「导出维护配置 / 导入维护配置」两个按钮移入折叠节。

### 三处范围写清（避免再混淆）

| 位置 | 范围文字 |
| --- | --- |
| 群卡 | 「备份 **本群** 配置」+ 范围说明行 |
| 总览 | 「备份 **所有群** 的配置」+「导入按群号覆盖合并，不影响备份以外的群」 |
| 维护页 | 「备份 **本群维护设置**」+「仅定时/容量/老文件/查重，不含规则」 |

### 文件页分区

原来是三行工具栏混排，现拆成四个带标题的分区（浏览与筛选 / 批量操作 / 新建文件夹 / 搜索）：
「刷新」与「触发分类」并排放浏览区右侧；分页条单独一行；批量操作、新建、搜索各占一行。
