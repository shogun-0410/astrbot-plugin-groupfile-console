# v2.8.0 更新说明（群运维级 · 2026-10-29）

主题：**稳定内核 + 运维能力 + 面板增强**

## 稳定内核

- 客户端按事件所属平台绑定，不再只认第一个 aiocqhttp 平台；
- 按群互斥锁：整理/删除/移动/确认同群串行；
- 时间归一：秒/毫秒/未来/0 值统一，异常时间不参与 TTL；
- 配置校验：cron/规则/权限/TTL/容量/查重 clamp + 非法项丢弃；
- 扫描防护：深度/文件夹数/文件数/环保护，整理与查重共用；
- TTL 单次删除上限（默认 200）；
- 危险操作确认绑定「用户+群」，跨群不能确认。

## 运维能力

- 权限分级 view/move/delete/admin；
- 审计日志（删除/移动/整理/建文件夹/回收/还原），面板可查；
- 后台任务中心（整理/查重/扫描/发文件，进度/取消/历史）；
- 回收站还原（TTL recycle 记录原位置，`/gf 恢复` 或面板还原）；
- 试运行（`/gf 预览`、面板 TTL 预览）；
- 规则优先级（-100~100）；
- 容量趋势（每日采样 + 总览柱状）；
- 定时补跑（错过 cron 在窗口内补一次）；
- `/gf 列` 分页 30/页。

## 面板

- 新增「任务」「审计」页；
- 文件页分页 + 上一页/下一页；
- 群配置角色权限编辑；
- 规则行优先级输入；查重模式补 smart/exact；
- 定时整理补跑窗口；TTL 试运行按钮；
- 总览容量趋势；响应式窄屏适配。

## 升级

- 覆盖安装 → 重载插件/重启 → 控制台 `Ctrl+F5`；
- `groups.json` 升 version 3，旧配置自动迁移（规则补 priority、权限从管理员名单映射）；
- 旧审计/任务/回收站文件不存在时自动新建。
