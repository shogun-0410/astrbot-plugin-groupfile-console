快速说明

  • 群配置：添加 / 删除群、备注名、启用开关、该群管理员，以及整套配置的 📤 导出 / 📥 导入。
  • 分类规则：关键词 / 构建器 / 正则规则；文件类型内置漫画 cbz/cbr、电子书、文档等 130+ 种，也能自定义扩展名；可从文件名智能生成，也能扫描群文件批量生成，可立即执行一次分类。规则卡片默认收起，点「展开」编辑匹配内容/类型/排除词，也可一键全部展开或收起。
  • 定时与维护：定时自动整理流水线（可多时间点）、按时间分文件夹的时效清理、容量提醒线（跟随定时任务播报）、查重规则与查重扫描。
  • 文件管理：浏览文件夹、按类型筛选（漫画/电子书/音视频…）、勾选删除 / 移动、新建文件夹、关键词搜索并可发到群。
  • 命令：聊天内用 /群文件 或短前缀 /gf（状态 / 列 / 查 / 删 / 移 / 建 / 整 / 开 / 关 / 绑 / 解 / 管 / 诊 / 确认），详见帮助页。
